# Industry Kubernetes Project

A hands-on DevOps project for deploying and managing an application on Kubernetes.

## Technology Stack

- Docker
- Kubernetes
- Minikube
- kubectl
- Helm
- GitHub Actions
- Prometheus and Grafana

## Project Goals

- Containerize an application
- Deploy it using Kubernetes manifests
- Configure Services, health probes, and resource limits
- Manage development and production configurations
- Automate builds and deployments with CI/CD
- Add monitoring and logging
